# Sistem Pembayaran SPP Digital

Proyek landing page dan dashboard simulasi untuk sistem pembayaran SPP sekolah berbasis web. Aplikasi ini dibuat menggunakan HTML, CSS, dan JavaScript murni.

## Fitur

- Halaman login dengan pilihan peran:
  - Wali Murid
  - Siswa
  - Bendahara / TU
- Dashboard utama
- Daftar tagihan SPP
- Riwayat pembayaran
- Notifikasi
- Modal pembayaran demo dengan metode:
  - QRIS
  - E-Wallet
  - Virtual Account
- Tampilan responsif untuk desktop dan mobile

## Struktur File

- `Indec.html` - struktur halaman utama
- `style.css` - styling aplikasi
- `script.js` - logika aplikasi dan interaksi

## Cara Menjalankan

1. Buka folder proyek.
2. Jalankan file `Indec.html` di browser.
3. Masukkan username dan password bebas sesuai kebutuhan demo.
4. Pilih role login lalu masuk ke dashboard.

## Catatan

Aplikasi ini merupakan simulasi frontend, sehingga data bersifat lokal dan tidak terhubung ke database atau backend nyata.
